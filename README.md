# Sonrieme · Sitio web de consultorio odontológico

Sitio web del consultorio odontológico **Sonrieme** de la Dra. María Paula R. Quiroz, en Bogotá: servicios, casos de antes y después, video y contacto directo.

- Sitio estático en HTML, CSS y JavaScript, adaptable a móvil
- Galería de casos clínicos (antes y después) y video del consultorio
- Proyecto de [Nómada Estudio Digital](https://nomadaestudio.digital)
